# Лабораторна робота №9

Простий React-застосунок на Vite, який демонструє JSX, компоненти, props, списки та `useState`.

## Запуск

```bash
npm install
npm run dev
```

## Перевірка

```bash
npm test
npm run build
npm run preview
```

## Основні файли

- `src/App.jsx` — структура з header, sidenav, main і footer.
- `src/data/news.js` — mock-дані новин.
- `src/components/` — повторно використовувані компоненти.
- `src/pages/Home.jsx` — стан компактного режиму та головна сторінка.

Кнопка над картками змінює звичайний вигляд на компактний і навпаки.
