# Laboratory Work No. 9

A simple React application built with Vite. It demonstrates JSX, components, props, lists, and `useState`.

## Run

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

## Main files

- `src/App.jsx` contains the shared header, sidebar, main content, and footer layout.
- `src/data/news.js` contains mock news data.
- `src/components/` contains reusable React components.
- `src/pages/Home.jsx` stores the compact view state and renders the home page.
- `src/pages/About.jsx` loads team data and displays different online photos.
- `src/pages/Contacts.jsx` renders the contact form.

The button above the news cards switches between normal and compact views.
